# Geoportal de Turismo Rural: Quindío y Cali Rural

Visor geográfico interactivo diseñado para la visualización, análisis y gestión de datos territoriales orientados al turismo rural en el departamento del Quindío (Paisaje Cultural Cafetero) y la zona rural del municipio de Santiago de Cali (15 corregimientos).

---

## 🚀 Características Principales

* **Visualización de Capas Vectoriales:** Carga dinámicamente archivos GeoJSON para representar límites municipales y corregimentales.
* **Mapa Interactivo (Leaflet):**
  * Alternancia entre capas base (Mapa Político / Vista Satelital).
  * Zoom automático (`flyTo` y `fitBounds`) al seleccionar una región o interactuar con un polígono.
  * Resaltado visual (*hover*) y ventanas emergentes (*popups*) con datos específicos de la unidad territorial.
* **Panel Lateral Informativo:**
  * Métricas clave de impacto socioeconómico y ambiental.
  * Tablas de atributos con datos de cobertura y uso del suelo.
  * Gráficos estadísticos dinámicos integrados mediante **Chart.js**.
* **Arquitectura Modular:** Estructura desacoplada (`data.js`) que facilita la incorporación futura de nuevas capas, gráficos o tablas de atributos sin modificar el código base del mapa.
